# ROS2  
  
## Setting up  
  
I would highly recomend using Ubuntu. You can do this by VM, Dualbooting or docker/distrobox.  
  
### Install:  
  
Here in the docs: https://docs.ros.org/en/lyrical/Installation.html  
  
### Workspace  
  
#### Make a workspace with this command:  
  
``` Bash
mkdir -p ~/ros2_ws/src  
cd ~/ros2_ws
```
  
#### Build:  
``` Bash
colcon build
```
  
Anytime you code it needs to be in src. When ever you want to run code you have to go to the root of the workspace and use the build command.
